## 📋 The 2026 GEO Checklist for Founders & Agencies

1. **Verify AI Bot Reachability**
   - Check `robots.txt` for `GPTBot`, `Claude-Web`, `PerplexityBot`.
   - Ensure Cloudflare / CloudFront "Bot Fight Mode" does not indiscriminately block AI indexers.
2. **Deploy Standardized `llms.txt`**
   - Place an `llms.txt` file at your domain root (`https://yourdomain.com/llms.txt`).
   - Cite your product's core entities, pricing, and API docs with markdown headings.
3. **Inject JSON-LD Entity Graphs**
   - Implement `SoftwareApplication`, `FAQPage`, and `Organization` schema markup.
4. **Audit Semantic Density**
   - Answer high-intent questions in direct, declarative paragraphs.
